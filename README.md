## 🚀 How to Play Right Now (Super Easy — 10 Seconds)

You do **NOT** need any coding knowledge or software installed!

1. Open this folder on your computer.
2. Find the file named **`index.html`** and **double-click it**.

5. Click **"🚀 Launch Game"** on any game card to start playing right away!

### 🏎️ Category 1: 3D Racing & Action — *Project Apex 3D Racing*

> **Folder**: [`/apex`](./apex/)  
> **Direct Launch**: Open `apex/index.html`

#### 🚘 What is this game?
A high-speed 3D car racing game. You get behind the wheel of a sleek race car on a custom asphalt track, racing against smart computer-controlled opponents while managing turns, drift mechanics, and camera angles.

#### ✨ Why it's awesome:
- **Real 3D Graphics**: Built using modern 3D WebGL graphics with dynamic lighting, tire smoke, and spark effects.
- **Smart Opponents**: Other cars on the track will race against you, compete for positions, and take racing lines.
- **Multiple Camera Views**: Switch between a third-person camera (behind the car) and a thrilling first-person hood/cockpit view.
- **Engine Sounds & Drifting**: Realistic engine sounds and tire screeching when taking sharp corners.

#### 🎮 Keyboard & Touch Controls:
| Key / Button | Action |
|---|---|
| **`↑` or `W`** | Accelerate / Speed up |
| **`↓` or `S`** | Reverse / Brake |
| **`←` or `A`** | Steer Left |
| **`→` or `D`** | Steer Right |
| **`Spacebar`** | Handbrake (use for sharp drifting turns) |
| **`C`** | Change Camera view |
| **`R`** | Reset car position back on track if you spin out |
| **On Mobile / Tablet** | On-screen touch steering and pedals are automatically shown |

### ♟️ Category 2: Strategy & Mind Sports — *Apex Chess Master*

> **Folder**: [`/chess`](./chess/)  
> **Direct Launch**: Open `chess/index.html`

#### ♟️ What is this game?
A complete master chess platform that lets you play, learn, solve puzzles, and improve your chess skills. Perfect for total beginners learning how the pieces move all the way to experienced tournament players.

#### ✨ Why it's awesome:
- **10 Bot Difficulty Levels**: From Elo 600 (friendly beginner bot who makes easy mistakes) up to Elo 2500+ (grandmaster level that plays near-perfect moves).
- **4 Unique Bot Personalities**:
  1. *The Valkyrie*: Aggressive attacker who loves sacrifices and fast attacks.
  2. *The Architect*: Solid positional defender who builds strong pawn walls.
  3. *The Magician*: Tricky tactical player who loves forks and pins.
  4. *Harmonic*: Balanced, classic tournament style.
- **Personal Chess Coach & Game Review**: Analyzes your moves after the game, showing you your best moves, missed wins, and mistakes with a colorful accuracy score.
- **Tactical Chess Puzzles & Rush**: Solve 15 hand-crafted chess puzzles with timer modes (3-minute and 5-minute rush).
- **Opening Explorer & Endgame Drills**: Practice master openings (like the Sicilian Defense) and endgame checkmate drills against a live computer defense.

#### 🎮 How to Play:
- **Mouse**: Click on any piece you want to move, and green dots will show all legal squares you can move to. Click the destination square (or drag and drop).
- **Keyboard Shortcuts**: Use `←` / `→` arrow keys to step through moves during game review.

### 🎲 Category 3: Family & Multiplayer Board Games — *Apex Ludo Royale*

> **Folder**: [`/ludo`](./ludo/)  
> **Direct Launch**: Open `ludo/index.html`

#### 🎲 What is this game?
The beloved world-famous board game of Ludo recreated with vibrant colors, a smooth 15x15 board, 3D rolling dice, sound effects, and online multiplayer capability!

#### ✨ 4 Ways to Play:
1. **Quick Play**: Jump into an instant game.
2. **Play with Friends (Private Room)**: Click create room, get a 6-letter room code (e.g. `AB7K9`), and send it to your friends so they can join from their own devices!
3. **Play vs Computer**: Play solo against 1, 2, or 3 computer players with 4 difficulty settings (Easy, Normal, Hard, Expert).
4. **Local Pass & Play**: Play with 2 to 4 people sitting together using one computer or tablet.

#### 📜 Basic Ludo Rules:
- Roll a **6** to bring a new token out of your yard onto the starting square.
- Rolling a **6** also gives you an **extra bonus roll**!
- Move your tokens clockwise around the outer track toward your colored home path.
- If your token lands on an opponent's token, you **capture** it and send it back to their yard (plus you earn a bonus roll)!
- Tokens on **Star squares (Safe Zones)** cannot be captured.
- The first player to move all 4 tokens into the center Home triangle wins the game! 🏆

#### 🎮 How to Play:
- Click the **3D Dice** in the center or bottom corner to roll.
- Click on any highlighted **Token** to move it forward.

### ⭕ Category 4: Quick Casual & Logic Puzzles — *Apex Tic-Tac-Toe*

> **Folder**: [`/tictactoe`](./tictactoe/)  
> **Direct Launch**: Open `tictactoe/index.html`

#### ⭕ What is this game?
The classic X and O game reimagined with futuristic cyberpunk neon graphics, glowing particle explosions, and smooth sound effects.

#### ✨ Why it's awesome:
- **Unbeatable Smart AI**: Test your wits against a computer AI that calculates every possible move. Can you force a draw?
- **2-Player Local Mode**: Play against a friend sitting beside you.
- **Difficulty Switcher**: Switch between Easy (relaxed fun), Medium (balanced), and Master (unbeatable).
- **Scoreboard**: Automatically tracks your wins, losses, and ties.

#### 🎮 How to Play:
- Simply click any open square on the 3x3 grid to place your **X** or **O**.
- Get 3 in a row horizontally, vertically, or diagonally to win!

## 💻 For Developers & Power Users (Optional Setup)

If you want to modify code, run development servers, or work with the live TypeScript source code:

### 1. Requirements
- Node.js (version 18 or newer)
- Modern web browser

### 2. Running the Arcade Locally with a Live Server
```bash
# In the root game directory:
npx serve .
# Then open http://localhost:3000 in your browser
```

### 3. Developing Apex Chess
```bash
cd chess
npm install
npm run dev      # Starts fast development server on http://localhost:5173
npm run build    # Compiles and checks all TypeScript types
npm run lint     # Runs Oxlint code quality checker
```

### 4. Developing Apex Ludo
```bash
cd ludo
npm install
npm run dev      # Starts client web server
npm run server   # Starts the WebSocket multiplayer room server
npm test         # Runs the 13 automated game engine tests
```

## 🛠️ How to Fix Bugs, Update, or Add New Features

If you want to update any game in the future:
1. **Find the game's folder**: Go to `apex/`, `chess/`, `ludo/`, or `tictactoe/`.
2. **Make your edits**: All source code files have clear names (e.g. `rules.ts` for game rules, `ai.ts` for computer difficulty).
3. **Test your changes**:
   - For Chess: run `npm run build` in `chess/` to verify zero TypeScript errors.
   - For Ludo: run `npm test` in `ludo/` to verify all 13 rules tests pass.
4. **Push to GitHub**:
   ```bash
   git add .
   git commit -m "fix: your clear update message"
   git push origin main
   ```

## ❓ Frequently Asked Questions (FAQ)

#### Q1: Do I need an internet connection to play?
> **No!** All 4 games are completely self-contained and run 100% offline right in your browser. (The only optional feature that uses a network connection is creating online private rooms in Ludo).

#### Q2: Does this work on phones and tablets?
> **Yes!** All games and the Arcade Launcher are fully responsive and support touchscreen controls, mobile layouts, and tablet screens.

#### Q3: Can I play with a game controller?
> In *Project Apex 3D Racing*, keyboard and touch are natively supported. You can also map controller analog sticks to Arrow/WASD keys.
